# legend of wildmoor

a one-file browser action rpg set in wildmoor and gehenna.

download [legend_of_wildmoor_v3.8.5.html](legend_of_wildmoor_v3.8.5.html) and open it in a browser. no install or build step.

there is also a retro edition, the same game drawn the way a 1998 console drew it(AND I MUCH PREFER IT...): [legend_of_wildmoor_v3.8.5_retro.html](legend_of_wildmoor_v3.8.5_retro.html) — [what it looks like](docs/updates/3.1_retro.md) · [its test notes](docs/QA_3.1_retro.md).

play it in the browser at [phonehseng.github.io/project-game](https://phonehseng.github.io/project-game/) — the [retro edition](https://phonehseng.github.io/project-game/retro.html) too.
