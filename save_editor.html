Builds a WM1- key (format v4) that the game's Load key box accepts. Nothing here loads or needs the game; the payload is constructed from scratch. Field names, bounds, quest titles and landmark coordinates were read out of the game source.

Permanent upgrades P.bonus

These are the keepsakes and relics, multiplied or added into the player once. Every range below is the game's own validator bound — a value outside it makes the whole key fail to load, silently, with only a console warning. guard is the one where lower is better: it scales every blow you take.

Skills SK

The game raises skills to 30 and stops; the save validator permits up to 99, so a higher level loads and simply never grows. The hero level is the average of the five land skills, lifted by swimming when swimming runs ahead of them.

Name and appearance CUSTOM

The name is sanitised on load: the six characters the game strips from every string are removed and it is cut to 24. An empty name falls back to a random one from the game's own list of thirty.

Satchel, pickups and herbs found · items · picked · owed

Settings carried in the key

The game overrides the three volume sliders, the mouse sensitivity and the spoken-dialogue box with this machine's own saved preferences straight after applying a key, so those are near enough cosmetic here. gfx is fixed at 3, which is what the game writes and what makes it honour hq and grass at all.

Raw JSON escape hatch for anything this form does not cover

Edit the payload directly and press Apply. This is the way to reach a field the form has no control for — the validator keeps only the keys it knows inside ws, bonus, story and settings and silently drops the rest, so adding one is harmless. Anything the form does know about is rewritten from the form on your next edit, so apply raw JSON last.
